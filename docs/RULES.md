# RuleDefinition v1

每个策略使用一份可版本化 JSON。前端条件卡片只是该格式的可视化编辑器。

## 条件树

组节点：

```json
{
  "type": "group",
  "op": "AND",
  "negate": false,
  "children": []
}
```

条件节点：

```json
{
  "type": "condition",
  "left": {
    "kind": "price",
    "field": "close"
  },
  "operator": "crosses_above",
  "right": {
    "kind": "indicator",
    "indicator": "SMA",
    "field": "value",
    "params": { "period": 20 }
  },
  "label": "价格上穿 SMA20"
}
```

操作数类型：

- `price`：open、high、low、close、volume。
- `indicator`：指标、参数、输出字段和历史偏移。
- `number`：常数。

比较符：`>`、`>=`、`<`、`<=`、`==`、`crosses_above`、`crosses_below`。

## 指标输出

- SMA、EMA、RSI、ATR、ROC、HIGHEST、LOWEST、VOLUME_SMA、DEVIATION：`value`。
- MACD：`macd`、`signal`、`histogram`。
- BOLLINGER：`upper`、`middle`、`lower`。
- HIGHEST/LOWEST 默认 `exclude_current=true`，突破条件不会把当前K线加入历史极值。

## 仓位

- `percent_equity`：账户净值百分比。
- `fixed_notional`：固定美元金额。
- `fixed_qty`：固定股数。
- `risk_based`：将 `value` 视为账户风险百分比，根据止损距离计算数量。

`allow_pyramiding` 控制是否允许已有持仓继续买入，`max_additions` 限制追加次数。

## 订单与保护

- 市价订单直接提交。
- 限价买单使用信号价格减去 `limit_offset_bps`。
- 同时设置 stop_loss 和 take_profit 时创建 Alpaca bracket 订单。
- trailing_stop 与 bracket 互斥；移动止损在买单完全成交后单独提交。
- 扩展时段固定关闭，TIF 只允许 DAY 或 GTC。

## 方向与品种

`direction` 默认 `long`、`instrument` 默认 `stock`，旧策略定义不变。

**股票做空**（`direction: "short"`）

- 入场条件成立时卖出开空，离场条件成立时买入平空；信号动作分别记为 `short` / `cover`。
- 只做 Alpaca 标记为可做空且易借券（ETB）的股票，整股下单；账户需开通做空（净值至少 2,000 美元）。
- Bracket 止损在开空价上方、止盈在下方；不支持移动止损，也不能用于 Paper 买卖验证。
- 同一标的不会同时存在策略多头和空头：持有多头时不开空，存在空头时不开多。
- 执行安全核对把做空标的的策略归属记为负数：券商空头必须与策略归属空头完全一致，平空买单不能超过实际空头。未归属的空头、超额做空或做空标的出现多头仍会立即隔离。
- 现金管理不会把做空所得计为闲置资金。

**买入期权**（`instrument: "option"`，`direction` 必须为 `long`）

- 条件在标的K线上计算；入场时从当前上市合约中选出一张：到期天数在 `min_dte`–`max_dte` 之间并最接近区间中点，行权价按 `atm` / `otm_pct` / `itm_pct` 与 `strike_offset_pct` 选最接近的一档；可要求最小持仓量和最大买卖价差。
- 只买入开仓（看涨 `call` 或看跌 `put`），不卖出开仓。仓位按权利金计算：每张 = 权利金 × 100，取整张；不能用 `risk_based`。
- 不支持 bracket 和移动止损。引擎每轮按期权买价检查 `stop_loss_pct` / `take_profit_pct`，并在距到期不超过 `close_dte` 天时平仓（`close_dte` 必须小于 `min_dte`）；离场条件成立时卖出该标的下的全部策略合约。
- 期权订单当日有效、常规时段；报价来自 Alpaca 免费 indicative 数据（不是交易所实际报价）。报价超过风险中心的行情有效期时，不会入场，也不会触发权利金止损止盈。
- 若合约持有到期：券商移除持仓后，对账按到期活动结算策略归属——价外作废记成交价 0；被行权/指派按到期日收盘内在价值结算，交割产生的正股不归属策略（看跌行权产生的空头会被隔离）。不会因到期误判为超卖而隔离。

当前只有 Alpaca 接入支持做空和期权；IBKR 接入下启用会被拒绝。

## 回测约定

- 当前K线收盘后才能产生信号。
- 市价信号在下一根K线开盘成交。
- 限价买单在信号后才可成交，成交价不超过买入限价。DAY 单在首个可执行交易日结束后失效；GTC 单可跨日等待。
- 同一K线同时触及止损和止盈时优先止损。
- 回测不模拟部分成交和订单队列，默认佣金为0、滑点为5基点。
- 预热行情在回测开始日期之前读取；预热不足时不生成信号。区间之前的行情不计入收益，也不会生成待成交订单。
- ATR保护价使用信号K线的已知指标，并分别遵守止损/止盈的ATR周期；不会读取成交当根K线未来的最高最低价。
- 回测遵守策略交易星期、最大持仓数、每标的冷却K线，并冻结当前用户的全局仓位、敞口、日亏损与日内回撤限制。触发账户熔断后，本次回测停止新信号，已有保护单仍可执行。
- Bracket、移动止损和GTC入场采用整股数量，并向下取整，不突破仓位预算。普通DAY单支持六位小数股数。
- 移动止损采用上一根已完成K线的最高水位；本根最高价抬升的止损从下一根起生效。这是明确的OHLC路径近似，不模拟逐笔成交。
- Sortino以0为最低可接受收益，用全部周期计算下行偏差；分母为零的Sharpe、Sortino、盈亏比与Profit Factor显示“—”，不以999代表无限值。CAGR按实际经过时间年化。
- 期末持仓按最后收盘价并计入滑点、佣金模拟平仓；该笔交易纳入胜率与交易数。基准缺失起始价格时会明确报错，不用未来价格回填。
- 回测实验室可以临时覆盖 `symbols`，把同一套指标和交易规则应用到其他股票或ETF；此覆盖只属于该次回测，不会修改或启用原策略。
- 基准可选择 SPY、QQQ、IWM、DIA、VTI、VOO、RSP 或 XLK，用于比较同期买入持有表现。
- 做空回测：下一根开盘卖出（滑点使成交更低），平仓买回（滑点使成交更高）；开空总市值不超过账户净值（1 倍）；止损按最高价、止盈按最低价触发，跳空时按开盘价成交；不计借券费（Alpaca 对 ETB 股票不收）。
- 期权回测使用真实历史期权K线（Alpaca 从 2024 年 2 月起提供），开始日期早于 2024-02-01 会被拒绝。每次入场按信号当天上市的合约（含已到期合约）用同一选择规则选合约，并且只接受在信号时点之前已有成交K线的合约（避免选中之后才挂牌的合约），在信号后的下一根期权K线开盘买入；当根标的K线之前没有期权成交则放弃该次入场。权利金止损止盈按期权K线最低/最高价触发，临近到期按规则平仓，仍持有到期则按内在价值结算。历史持仓量不可用，因此回测不应用最小持仓量和价差过滤。合约列表与期权K线一并写入实验快照，可离线复现。

## 实验快照

新回测绑定规则定义、策略版本、风险配置，保存压缩的完整输入行情、数据SHA-256及计算代码/依赖标识。结果页可下载自己的实验快照；旧记录不会伪造缺失数据。回测列表不加载大体积行情。

使用与快照一致的代码和Python依赖，在离线环境复跑：

```bash
.venv/bin/python scripts/replay-backtest.py backtest-<id>.json.gz
```

脚本不访问券商或数据库；行情校验和、代码或依赖版本不一致会拒绝静默复现。快照包含私有策略定义，分享前应检查内容。
